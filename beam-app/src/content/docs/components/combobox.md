---
title: Combobox
description: A text field that filters a long list as you type.
---

## Import

```tsx
import { Combobox } from "@/components/ui/combobox";
```

## Examples

### Basic

Use it when a Select would have more options than fit on screen.

```demo
combobox/basic
```

## Accessibility

- Typing filters; arrow keys move; Enter selects; Escape closes.

## Tokens used

`--bg-control`, `--bg-popover`, `--bg-highlight`, `--bg-surface`, `--border-default-color`, `--radius-s`, `--radius-xs`.
