---
title: Scroll area
description: A fixed-height region whose content scrolls.
---

## Import

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";
```

## Examples

### Basic

```demo
scroll-area/basic
```

## Accessibility

- The content scrolls with the keyboard and with touch as a normal region does.

## Tokens used

`--bg-surface`, `--bg-track`, `--border-default-color`, `--text-secondary`, `--radius-s`, `--radius-full`, `--space-m`.

## Follows

The **Scroll area** assignment.
