title: Popover
description: A small panel of extra detail that opens from a control.
---

## Import

```tsx
import { Popover } from "@/components/ui/popover";
```

## Examples

### Basic

```demo
popover/basic
```

## Accessibility

- Focus moves into the popover and returns to the trigger on close. Escape closes it.
- It opens from its trigger and scales from 0.96.

## Tokens used

`--bg-popover`, `--border-default-color`, `--text`, `--text-muted`, `--radius-m`, `--space-m`, `--space-xs`.
