---
title: Accordion
description: Stacked headings that open to show their content.
---

## Import

```tsx
import { Accordion } from "@/components/ui/accordion";
```

## Examples

### Basic

The third item is disabled.

```demo
accordion/basic
```

## Accessibility

- Each heading is a button and reports whether its panel is open.
- The panel fades in. Its height is not animated.

## Tokens used

`--border`, `--text`, `--text-secondary`, `--text-muted`, `--radius-s`, `--space-m`.
