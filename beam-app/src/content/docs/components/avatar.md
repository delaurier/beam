title: Avatar
description: Stands for a person, using their initials when there is no picture.
---

## Import

```tsx
import { Avatar } from "@/components/ui/avatar";
```

## Examples

### Initials

```demo
avatar/basic
```

## API reference

| Prop | Type | Notes |
| --- | --- | --- |
| `name` | string | Used for the initials and the accessible name. |
| `src` | string | Optional picture. |

## Accessibility

- The person's name is the accessible name.

## Tokens used

`--bg-surface-muted`, `--text-secondary`, `--radius-full`, `--space-xxl`.
