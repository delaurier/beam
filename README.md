# Beam

Farm-management software: crops, land, machinery and finance.

| Folder | What it is |
| --- | --- |
| `beam-app` | The coded design system and the product prototype (Next.js). Start here. |
| `beam-theme` | The Graphical theme export Beam's values come from (`GUI.md`, `gui/`, skills). |
| `beam-screens` | The Paper screen generator (`_generator/`) and rendered screen images. |
| `beam-assets` | Moodboard photos referenced from the Paper file. |
| `beam-app-gif` | Earlier mobile screens and the X post composition and video. |

## Run the app

```bash
cd beam-app
npm install
npm run dev
```

Then open http://localhost:3000. The design system is at `/docs`; the product screens are at `/app`.
